# Data Analytics Projects

A portfolio of notebook-based exercises in image processing, sports data, country-level GDP, and movie ratings.

## Project index

| Project | Contents |
| --- | --- |
| Project 1 | Image reading and processing with NumPy, Matplotlib, and PIL |
| Project 2 | IPL data analysis with NumPy and Matplotlib |
| Project 3 | Country GDP analysis using the included CSV |
| Project 4 | Movie-rating analysis using the included dataset |

Open the notebook in each project folder to see the analysis and visualizations. The datasets and image assets used by the notebooks are stored alongside them.

## Tools

Python · Jupyter Notebook · NumPy · Matplotlib · PIL/pillow · pandas
